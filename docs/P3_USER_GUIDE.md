# P3 GPU训练与模型仓库操作指南

仅源码开发版；PACKAGING_FREEZE = TRUE，不更新Word/PDF或EXE/Portable。双击根目录“启动IVAD.cmd”，关闭旧源码实例后再启动；当前源码Schema0009，旧Beta.2不支持新Schema，勿用旧包打开已升级项目。

## 训练前准备

目的：使用已保存人工真值并完成质量检查的实验检测数据。步骤：在P2保存正常无框或异常目标框/多边形→数据集管理四个Tab筛选、创建草稿、预览划分及冻结。无需再次逐张提交人工审核；旧审核原值保留，实验准入记录AUTO_CHECKED_HUMAN，不冒充独立审核。完整操作见 [数据集管理指南](P3_DATASET_USER_GUIDE.md)。Train和Val须非空；来源不足为LIMITED，需要真实独立来源，不可把随机连续帧当成工业泛化证据。正常背景为空标签；未知、冲突、剔除及异常无框拒绝Detection。已有冻结版本沿用其原审核政策，不会被自动升级或修改。

## 简易与高级训练

目的：不写代码启动CUDA训练。步骤：开发模式→打开正确项目→设备与后端执行检查→AI训练→选择所属数据集和冻结版本、yolo26n或yolo11n、可用NVIDIA GPU→选择简易训练→训练前检查→启动GPU训练。默认20轮、640、batch4、SGD、学习率.01、衰减.0005、patience10、seed123、增强开、FP32。高级模式允许调整这些数值，图像尺寸须为32倍数，批次1–64，轮数1–10000，AMP开为混合精度；普通操作无需YAML或命令行。初始权重默认使用已验证的本地P0官方权重，也可选择已登记可信模型。结果：后台排队，任务中心显示状态；GUI保持可操作。问题：无GPU须先设备检查；显存不足减小批次/图像尺寸重试，不切换CPU。

## 进度、取消和恢复

目的：查看真实训练结果或停止任务。步骤：选择训练记录，查看epoch、train/val loss、Precision/Recall/mAP、显存/耗时；下方滚动查看曲线，切换“混淆矩阵（适用时）”。点击“取消所选训练”，核对完整TrainingRun ID并确认后合作取消保留已完成epoch检查点，超过20秒可能终止Worker。恢复：选择同数据集与架构，在“条件恢复（沿用原参数）”选失败/取消的原记录，训练前检查通过后启动。已完成的模型从“初始权重”选择以启动独立微调，不作为中断恢复。结果：从完整epoch检查点继续，另建训练目录，不覆盖原实验。问题：尚未完成任何epoch时可能没有可恢复检查点；完成的最后一轮不能无限续训，需新实验。训练日志位于界面显示的项目相对路径worker-console.log，诊断日志/任务中心可定位错误。

## 独立模型验证

目的：用冻结验证集复测已登记模型。步骤：AI训练→选择冻结数据集、模型架构、GPU，在初始权重中选已登记版本→点击“验证所选初始模型”。结果：后台记录真实验证指标和混淆矩阵，并关联模型版本。问题：类数或类别名称顺序不符会拒绝；不能把COCO权重直接当作已训练的堵煤模型。验证不自动发布。

## 模型仓库与审批

目的：管理实验、候选和生产注册版本。步骤：模型仓库→刷新→选择版本→完整性检查。训练模型默认EXPERIMENTAL；导入只接收用户明确确认可信来源的PT/ONNX，并选择实际架构声明，未验证前不能申请候选。确认验证指标达到所设门槛后点击申请候选。默认Precision/Recall/mAP50≥0.5，mAP50-95≥0.25；修改门槛要符合项目实际审核要求，软件阈值不是工业安全证明。批准生产注册必须在GUI确认；取消确认则不改变状态。回滚时选择曾发布的历史版本并明确确认。结果：仅一个项目生产注册指针，旧文件/历史保留，不部署摄像头或自动报警。问题：SHA损坏、旧修订、未达门槛会阻止操作，刷新后核查，不删除数据库。

## 导出模型工件

目的：保存可追溯模型。步骤：选择版本→导出模型权重/ONNX→选择已有输出父目录。结果：新唯一目录含PT及可用ONNX、model_manifest.json、hash、类别映射、预处理/后处理和版本关联；不覆盖现有目录。此操作不制作应用程序安装包。ONNX已训练模型采用FP32/raw非端到端输出+NMS；不据此宣称Intel或其他GPU兼容。

## 测试与边界

本轮合成测试仅证明训练/验证/取消/恢复/审批管线工作；不是落料口堵煤工业准确率。真实视频必须由人工确认目标和审核，禁止把模型建议当真值。本轮没有P4报警/时序判断、P5预标注或P6打包。许可和长期稳定性限制见reports/P3_ACCEPTANCE.md。

## 训练配置界面 Hotfix（2026-10-16）

宽窗口左侧基础配置约40%、右侧参数约60%，顶部对齐；窄窗口上下排列，可滚动。五个操作宽窗口同排、窄窗口换行。简易训练显示推荐参数且只读；将鼠标放在参数上可查看中文说明，切换高级训练后可编辑。图像尺寸须为32倍数，非法设置会即时提示。

训练前检查验证冻结数据、参数、权重文件/架构、恢复条件、NVIDIA后端和Worker解释器。任何关键设置变化均使旧预检失效；启动前再次复核，重复点击不会创建重复任务。选中的训练记录下方JSON显示该任务实际parameters，新任务表单不修改运行任务。创建任务后参数由既有TrainingRun持久保存。

AMP仅在高级模式且有已检查的NVIDIA后端时允许选择，简易默认关闭。Worker真实传递amp参数并在启动时做本地CUDA AMP探测；失败记录错误，不回落CPU。本次仅验证配置传递与失败处理，没有重新训练或验证AMP的速度/精度。

“刷新数据与GPU”不会训练；“验证所选初始模型”验证的是所选初始模型，不等于新模型最终验证。微调建立新模型版本；中断恢复沿用原参数和epoch/优化器进度，保持既有独立续训目录/记录策略，原任务不覆盖。仅冻结版本能训练，LIMITED结果仅工程实验，不得宣称工业准确率。
