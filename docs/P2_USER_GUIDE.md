# P2鼠标操作指南

双击项目根目录“启动IVAD.cmd”。同一数据目录只能运行一个实例。沿用独立.venv-p1界面环境，GPU环境.venv-nvidia保持独立。

1. 项目管理：创建项目或选择包含project.json的已有项目文件夹。旧Schema首次打开前自动创建.migration-*.backup；切换/退出前等待标注保存完成。
2. 视频管理：默认“复制到项目”，点击“批量导入录像”，可提前填写摄像头编号/厂区/设备。COPY占磁盘；REFERENCE依赖外部文件原路径。Missing时选择录像、点击“重新定位引用”，新文件必须与原SHA256相同。扩展名不保证编码兼容。
3. 播放与定位：点击录像行，实际画面加载后可播放/暂停、逐帧前后、拖动时间轴、输入秒数跳转、选择速度。时间显示相对视频起点，PTS为实际显示帧时间；未知拍摄日期不等于导入日期。当前画面按钮保存人工候选帧。播放器只播放视频画面，无音频。
4. 抽帧设置：用当前画面设起点/终点，设置间隔、数量上限、PNG或JPEG/质量/最大宽度，再确认有限抽帧。最大宽度0保留原始尺寸；较小间隔实现指定时间段加密采样。变化筛选阈值越小越敏感，可保留固定基础样本，变化不代表工业异常。AI辅助显示Not Available，属于P5。任务中心查看进度/日志并取消；取消后完整图片保留，重启未完成任务为INTERRUPTED，可用相同参数重新抽帧。
5. 视频片段标签：抽帧设置页设范围，片段页设正常/异常/未知、故障类别、审核状态后保存。选中已有片段可修改或删除；新片段按钮解除已有选择。片段标签不转换成框。
6. 标注工作台：左侧按录像过滤候选图片，点击图片。选择类别和工具；矩形拖拽，多边形逐点点击、Enter或右键完成、Esc取消。选择工具移动对象；拖矩形角或多边形顶点编辑。滚轮缩放、中键平移、适应窗口、撤销/重做和删除选中。缩放不改变存储坐标。ROI工具与目标分开，可关联视频或同编号摄像头；共享ROI修改有修订冲突保护。小窗口右侧属性可滚动。
7. 整帧标签与审核：人工确认正常/异常/未知及整帧故障类别，完成后在数据集管理中独立审核为REVIEWED或APPROVED。自动保存延迟350ms，状态栏显示已保存修订；也可点击保存。DRAFT/REJECTED不进入数据集候选。保存失败时切换/退出会被阻止，修正后保存或明确放弃修改重载。
8. 故障类型按钮打开标签库：新类别、中文名称、说明、设备类型、父级、默认类型、启用状态均可编辑。重命名保持UUID；历史引用类别无法删除，可停用。初始类别只是模板，无已发布模型。默认类型是类别元数据，绘制工具仍由工具栏明确选择。
9. 数据集管理：选择人工审核图片，填写名称，先检查再冻结。推荐按摄像头或来源录像分组；少量来源无法精确实现70/20/10，统计显示真实数量。相同图片hash去重；近重复仅警告。随机划分必须勾选风险确认。选择已有数据集可冻结新版本；旧版本不修改，图片/标注/类别/ROI/片段保留快照。
10. 选择冻结版本和导出格式，选择已有父目录，程序新建唯一输出文件夹。YOLO Detection可将多边形转外接框并明确告知，原始多边形保留原生旁车；YOLO Segmentation只接受真实多边形，混有矩形框会拒绝。已审核正常无目标可作为空标签负样本，未知/异常未标注不能悄悄变成正常负样本。COCO或IVAD Native适合保存全部语义；每种导出附ivad_native.json和文件hash清单。缺失/篡改快照拒绝导出。

项目目录包含原始媒体副本media/、候选frames/、冻结datasets/、SQLite与清单；请整体备份。Reference源和外部导出目录需另外保留。一致性检查只报告问题，不删除用户资源。强制结束、拔盘、权限改变可能留.partial，勿手工覆盖旧版本；保留项目、日志和暂存目录后再恢复。

可打开artifacts/p2/gui-evidence-native/下的“P2合法样本与人工标注”项目熟悉流程。它是自制工程测试录像，不是选煤厂真值，不能据此评价工业模型性能。P3训练及后续功能仍需用户单独批准。

## 2026-10-14补充：左右布局与实际视频片段

视频管理改为左录像表、右操作区。拖动中间分隔条调整宽度，左表上下滚动浏览录像，横向滚动查看六列，悬停文件名查看全文；导入信息默认折叠，填写摄像头/厂区/设备时展开。右区内容较长时滚动，标签未选蓝白、悬停及激活白黑。

起点/终点现在位于右区顶部，四标签共用范围；可用播放器当前画面设起点/终点，也可手填秒数。“抽帧设置”每项下方直接显示中文解释。“取消当前录像抽帧”只取消当前选中录像的抽帧，不取消其他录像/项目任务。

选原始录像并设范围→“保存视频片段”页→可选名称/备注→“保存视频片段”。至少100毫秒且两帧，终点必须晚于起点且不超时长。后台进度在右下说明及任务中心，保存完成出现CLIP行。原录像仍保留，引用来源不会改变；新片段实际文件在项目media/，可直接播放/抽帧/标注/审核/数据集导出。此处保存实际MP4，“视频片段标签”页仍只保存时间标签，两者分别管理。

裁剪按实际帧边界[start,end)，重新编码H.264、首帧归零，只保留视频无音频，未实现片段再裁片段。输入与实际首末源时间都保存在clip_info。失败/提交前取消不生成完整CLIP；重复保存用新UUID，不覆盖旧片段。旧项目打开自动备份并升级0004，无需手工编辑SQLite。

本轮合法样例项目在artifacts/p2-adjustment/demo/，旧样例及证据保留。P3仍需另行明确批准。


## P2 UX v2 当前标注操作

右侧“所属摄像头”只读显示来源；摄像头创建编辑在项目管理的摄像头管理 Tab，视频页保存关联，显示名与UUID分开。同原录像及片段复用关联，帧/标注通过来源录像继承。没有摄像头仍可保存。视频ROI/摄像头ROI/目标框独立，名称改动不破坏历史关系。

剔除仅适用于模糊、花屏、曝光或丢失画面等无效图片，不用于无法判断工业故障。单帧或批量选择原因并确认；保留已有标注、审核与旧冻结集引用，只改变软剔除状态。默认有效帧筛选隐藏剔除；仅已剔除可查看，恢复当前/批量恢复保留原标注、审核、来源和操作历史。没有永久删除硬盘文件功能。

新数据集只接受已审核正常/异常的有效帧；未处理、未知、剔除、冲突排除。旧冻结集不修改。正常YOLO负样本为空标签，异常无框只能按相应原生标签任务使用，不能伪装正常。实际故障须用户或现场工程师确认，测试夹具不能当工业真值。

GUIDE正式Word第16–18页解释新快捷、摄像头、剔除流程，首页页码已实际核验。诊断日志可复制信息或导出脱敏ZIP，不自动上传。原生自动化会话曾出现访问冲突，独立复测通过但根因未定位；Beta.2仍仅本地审核候选，许可/跨机/长期稳定性未完成。仅P2，不进入P3。

## 2026-10-15 标注流程补充（当前源码，P2 Hotfix）

本节适用于当前源码；本轮不更新旧 Word/PDF 或分发包。标注不等于 AI 已学会故障，也不等于样本已审核。

### 按摄像头处理图片

**操作目的：** 避免处理另一台摄像头的图片。

**操作步骤：** 在左侧最上方摄像头下拉框选择目标摄像头；选项来自当前项目，可选“当前项目全部摄像头”或“未关联摄像头”。再按来源录像和处理状态筛选。右侧下方只读显示所属摄像头；需要关联时点“前往视频管理关联摄像头”。

**正常结果：** 列表只显示相符来源；切换筛选清除旧勾选。来源依 MediaAsset 的关联继承，不根据文件名自动猜测。

**常见问题：** 注册了摄像头不等于每条视频已关联。找不到图片时先查“未关联摄像头”；视频页明确关联后刷新。默认不允许跨摄像头批量操作；确有需要时勾选独立跨摄像头入口，并逐次确认两个提示。

### 剔除、恢复和移出工作列表

**操作目的：** 剔除无效图，或暂时不在当前列表处理某些图。

**操作步骤：** 勾选可见图片，点“批量剔除无效帧”，选择原因，核对预览中的已选、可处理、已有标注、旧数据集引用和跳过数量，再确认。查看左侧结果区的成功/跳过/失败数。单张可用“剔除当前帧并进入下一张”。

需要恢复剔除时，处理状态选“仅已剔除”，勾选后点“恢复已剔除”，或用右侧“恢复当前帧”。只想暂时移出列表时点“从当前批次移除”；在工作列表下拉框选“全部帧（含已移出）”或“仅已移出批次”，再勾选并点“移回当前批次”。

**正常结果：** 剔除后不参加新的训练集，但文件、标注、审核、修订和旧冻结集保留；恢复后内容仍在。移出批次仅改变列表成员状态，不改变训练资格或标注。

**常见问题：** 全部跳过也会弹出原因；反复剔除已经剔除的图不会重复更新。若事务冲突，显示失败且未部分提交，重新载入再选。当前仅有每项目一个默认工作列表，没有多个命名批次；普通操作员没有永久删除帧文件入口。“删除选中”仅删除当前画布目标标注，不是删除抽帧文件。

### 保存后自动更新已标注

**操作目的：** 让完成状态与真实保存内容一致。

**操作步骤：** 正常图选“正常”，无需画框，点“保存正常并下一张”。异常图选故障类型，画矩形或多边形并保存；未知帧画出合法目标后会自动切为异常。多边形逐点后右键或 Enter 完成。

**正常结果：** 数据库成功保存后显示“已标注”；正常图显示绿色标识，异常图显示红色标识。状态自动计算，常规界面没有手动状态下拉框。未保存或保存失败不会提前完成；异常既无框又无整帧故障类别时仍未完成。

**常见问题：** 无框正常合法，无 ROI 不阻断。有明确整帧故障类别的无框异常可作为分类内容保存，不能当作检测框真值。“已标注”不代表 REVIEWED/APPROVED；审核仍在数据集管理中进行，真值修改后需重新审核。

### ROI 自动来源与管理

**操作目的：** 使用合适的辅助区域，不必逐张选择作用域。

**操作步骤：** 默认自动采用当前视频有效 ROI，其次来源摄像头有效 ROI。查看当前帧底部 ROI 来源说明；需要管理时点“ROI 管理 / 来源说明”，明确选择编辑视频 ROI 或摄像头 ROI，再用 ROI 工具绘制和保存。无摄像头时仍可使用视频 ROI。

**正常结果：** 主界面不再显示 ROI 作用域下拉框；历史视频和摄像头配置分别保留，冲突优先视频，不合并。尺寸比例或旋转不匹配的旧区域保留但不自动应用。

**常见问题：** ROI 不是目标框，不触发 AI。物理摄像头移动后的视角变化不能只靠元数据自动发现，请人工检查区域。未关联摄像头时先在视频管理明确关联，不根据文件名自动匹配。


## 2026-10-15 标注工作台简化（最新源码）

### 连续标注与默认故障类型

**目的：** 连续处理同一机位时减少重复选择。

**步骤：** 在右侧“故障类型（用于新绘制目标）”选择类别，再绘制矩形或多边形。点“保存异常并下一张”，下一张沿用该摄像头本次会话的选择。切换摄像头后，各自保留自己的选择；未关联摄像头时按视频分别记忆，首次进入没有默认值时显示“请选择故障类型”。

**正常结果：** 新绘制对象使用默认类别；不会自动给下一张画框、复制坐标或写异常标签。正常和剔除图片不会因默认类别生成异常真值。

**常见问题：** 默认类别仅在当前窗口会话保留，重启需重新选择；停用类别不能作为新对象默认值。旧对象的真实类别在“当前对象”列表及只读故障汇总中显示，查看或选中旧对象不会改变工作默认值或其标注。

### 三个主要操作

- **保存正常并下一张：** 不需选择故障类型或 ROI。已有异常目标或整帧类别时先确认，历史修订保留；保存成功才翻页。
- **保存异常并下一张：** 先画合法目标，或在详情中明确整帧分类类别；保存当前内容后翻页。默认故障类型仅决定新对象初始类别。
- **剔除并下一张：** 选择原因并核对预览，软剔除后翻页。文件、原标注及历史保留，可恢复。

这三个名称带“下一张”的按钮始终在成功后请求翻页；到最后一张时不制造新图片。待复核仍可通过“当前处理方式”选择“未知/待确认”，使用待复核保存辅助入口；该入口可单独设置是否自动下一张。普通“保存标注”用于留在当前图。

### 已有对象及多类别

选择新的故障类型只改变后续绘制的默认值，不会改已有框。同一帧可逐次选择类别并画不同目标。需要修改已有对象类别时，先在“当前对象”选中它，再选故障类型并点“修改所选对象类别”。这是明确编辑动作，会沿用原保存及修订机制。

### 完成状态与整帧详情

常规界面不再提供“标注状态”下拉框，也不显示重复的“整帧故障类别”下拉框。左侧图标和 tooltip、当前帧信息说明真实保存后的完成状态；未保存、保存失败、未知、冲突、剔除不能冒充已完成。已标注不等于已审核，数据集管理中的审核仍须独立进行。

历史整帧类别没有删除。点击“整帧标签详情…”查看或修改；确认后沿用原自动/手动保存。无框整帧异常分类不会自动生成目标框，也不能当成 YOLO Detection 真值。只改变工作默认类别不修改历史整帧类别或冻结版本。
