# P2鼠标操作指南

双击项目根目录“启动IVAD.cmd”。同一数据目录只能运行一个实例。沿用独立.venv-p1界面环境，GPU环境.venv-nvidia保持独立。

1. 项目管理：创建项目或选择包含project.json的已有项目文件夹。旧Schema首次打开前自动创建.migration-*.backup；切换/退出前等待标注保存完成。
2. 视频管理：默认“复制到项目”，点击“批量导入录像”，可提前填写摄像头编号/厂区/设备。COPY占磁盘；REFERENCE依赖外部文件原路径。Missing时选择录像、点击“重新定位引用”，新文件必须与原SHA256相同。扩展名不保证编码兼容。
3. 播放与定位：点击录像行，实际画面加载后可播放/暂停、逐帧前后、拖动时间轴、输入秒数跳转、选择速度。时间显示相对视频起点，PTS为实际显示帧时间；未知拍摄日期不等于导入日期。当前画面按钮保存人工候选帧。播放器只播放视频画面，无音频。
4. 抽帧设置：用当前画面设起点/终点，设置间隔、数量上限、PNG或JPEG/质量/最大宽度，再确认有限抽帧。最大宽度0保留原始尺寸；较小间隔实现指定时间段加密采样。变化筛选阈值越小越敏感，可保留固定基础样本，变化不代表工业异常。AI辅助显示Not Available，属于P5。任务中心查看进度/日志并取消；取消后完整图片保留，重启未完成任务为INTERRUPTED，可用相同参数重新抽帧。
5. 视频片段标签：抽帧设置页设范围，片段页设正常/异常/未知、故障类别、审核状态后保存。选中已有片段可修改或删除；新片段按钮解除已有选择。片段标签不转换成框。
6. 标注工作台：左侧按录像过滤候选图片，点击图片。选择类别和工具；矩形拖拽，多边形逐点点击、Enter或右键完成、Esc取消。选择工具移动对象；拖矩形角或多边形顶点编辑。滚轮缩放、中键平移、适应窗口、撤销/重做和删除选中。缩放不改变存储坐标。ROI工具与目标分开，可关联视频或同编号摄像头；共享ROI修改有修订冲突保护。小窗口右侧属性可滚动。
7. 整帧标签与审核：人工确认正常/异常/未知及整帧故障类别，完成后选REVIEWED或APPROVED。自动保存延迟350ms，状态栏显示已保存修订；也可点击保存。DRAFT/REJECTED不进入数据集候选。保存失败时切换/退出会被阻止，修正后保存或明确放弃修改重载。
8. 故障类型按钮打开标签库：新类别、中文名称、说明、设备类型、父级、默认类型、启用状态均可编辑。重命名保持UUID；历史引用类别无法删除，可停用。初始类别只是模板，无已发布模型。默认类型是类别元数据，绘制工具仍由工具栏明确选择。
9. 数据集管理：选择人工审核图片，填写名称，先检查再冻结。推荐按摄像头或来源录像分组；少量来源无法精确实现70/20/10，统计显示真实数量。相同图片hash去重；近重复仅警告。随机划分必须勾选风险确认。选择已有数据集可冻结新版本；旧版本不修改，图片/标注/类别/ROI/片段保留快照。
10. 选择冻结版本和导出格式，选择已有父目录，程序新建唯一输出文件夹。YOLO Detection可将多边形转外接框并明确告知，原始多边形保留原生旁车；YOLO Segmentation只接受真实多边形，混有矩形框会拒绝。已审核正常无目标可作为空标签负样本，未知/异常未标注不能悄悄变成正常负样本。COCO或IVAD Native适合保存全部语义；每种导出附ivad_native.json和文件hash清单。缺失/篡改快照拒绝导出。

项目目录包含原始媒体副本media/、候选frames/、冻结datasets/、SQLite与清单；请整体备份。Reference源和外部导出目录需另外保留。一致性检查只报告问题，不删除用户资源。强制结束、拔盘、权限改变可能留.partial，勿手工覆盖旧版本；保留项目、日志和暂存目录后再恢复。

可打开artifacts/p2/gui-evidence-native/下的“P2合法样本与人工标注”项目熟悉流程。它是自制工程测试录像，不是选煤厂真值，不能据此评价工业模型性能。P3训练及后续功能仍需用户单独批准。

## 2026-10-14补充：左右布局与实际视频片段

视频管理改为左录像表、右操作区。拖动中间分隔条调整宽度，左表上下滚动浏览录像，横向滚动查看六列，悬停文件名查看全文；导入信息默认折叠，填写摄像头/厂区/设备时展开。右区内容较长时滚动，标签未选蓝白、悬停及激活白黑。

起点/终点现在位于右区顶部，四标签共用范围；可用播放器当前画面设起点/终点，也可手填秒数。“抽帧设置”每项下方直接显示中文解释。“取消当前录像抽帧”只取消当前选中录像的抽帧，不取消其他录像/项目任务。

选原始录像并设范围→“保存视频片段”页→可选名称/备注→“保存视频片段”。至少100毫秒且两帧，终点必须晚于起点且不超时长。后台进度在右下说明及任务中心，保存完成出现CLIP行。原录像仍保留，引用来源不会改变；新片段实际文件在项目media/，可直接播放/抽帧/标注/审核/数据集导出。此处保存实际MP4，“视频片段标签”页仍只保存时间标签，两者分别管理。

裁剪按实际帧边界[start,end)，重新编码H.264、首帧归零，只保留视频无音频，未实现片段再裁片段。输入与实际首末源时间都保存在clip_info。失败/提交前取消不生成完整CLIP；重复保存用新UUID，不覆盖旧片段。旧项目打开自动备份并升级0004，无需手工编辑SQLite。

本轮合法样例项目在artifacts/p2-adjustment/demo/，旧样例及证据保留。P3仍需另行明确批准。


## P2 UX v2 当前标注操作

源版本1.0.0-P2-UX.2，便携候选Beta.2；旧Beta.1已过期。关闭旧实例，重新启动IVAD；项目首次升级0005先自动保存SQLite备份，旧表/标注/修订不清空。

正常：选“正常”，故障类别自动清空并禁用，目标工具禁用，ROI可选。点“保存正常帧并进入下一张”；不需先设审核，也不会自动APPROVED。存在异常内容时必须确认；取消保留，确认后历史仍在，可“恢复历史标注…”。

异常：选“异常”，选类别并按实际区域画矩形/多边形，点“保存异常标注并进入下一张”。整帧异常无框可以保存，但不是检测框真值。未知：选“未知/待确认”，可填原因，点“保存待复核并进入下一张”。关闭自动翻页复选框可留当前，普通保存仍可用，Ctrl+S保存/Ctrl+Enter快捷。

左侧有复选框、处理图标和中文tooltip；状态与审核独立。可Ctrl/Shift多选、全选筛选结果、选未处理帧或取消。批量标记正常前必须人工检查；确认窗口显示可更新和冲突，异常/待复核/已审核/剔除/冲突跳过。失败整批回滚。

右侧“所属摄像头”允许选择、新建、重命名并保存关联，显示名与UUID分开。同原录像及片段复用关联，帧/标注通过来源录像继承。没有摄像头仍可保存。视频ROI/摄像头ROI/目标框独立，名称改动不破坏历史关系。

剔除仅适用于模糊、花屏、曝光或丢失画面等无效图片，不用于无法判断工业故障。单帧或批量选择原因并确认；已有真值、审核或旧数据集引用受保护并跳过。默认有效帧筛选隐藏剔除；仅已剔除可查看，恢复当前/批量恢复保留原标注、审核、来源和操作历史。没有永久删除硬盘文件功能。

新数据集只接受已审核正常/异常的有效帧；未处理、未知、剔除、冲突排除。旧冻结集不修改。正常YOLO负样本为空标签，异常无框只能按相应原生标签任务使用，不能伪装正常。实际故障须用户或现场工程师确认，测试夹具不能当工业真值。

GUIDE正式Word第16–18页解释新快捷、摄像头、剔除流程，首页页码已实际核验。诊断日志可复制信息或导出脱敏ZIP，不自动上传。原生自动化会话曾出现访问冲突，独立复测通过但根因未定位；Beta.2仍仅本地审核候选，许可/跨机/长期稳定性未完成。仅P2，不进入P3。

2026-10-15 v3：单帧“剔除当前帧并进入下一张”默认跟随自动下一张开关。剔除原因固定选择：严重模糊、图像解码错误、花屏或画面损坏、严重曝光异常、摄像头画面丢失、其他原因。轻微模糊由人工判断，不自动剔除。PACKAGING_FREEZE = TRUE；仅更新源码说明，原Word/PDF及Portable不更新。P2最终PASS后按本轮授权进入P3，不延伸到P4–P6。


## P2 Hotfix during P3（2026-10-15）

2026-10-15 Hotfix：以下步骤替代旧指南中标注页审核/摄像头编辑路径（Word/PDF未重制）。

1. 项目管理→项目详情/摄像头管理：双击最近项目名称进入正确项目的摄像头列表；新建/编辑编号、名称、位置、设备及启用状态，保存后UUID不变。可停用，无物理删除。
2. 视频管理→导入信息（可选，展开）：选择当前项目启用摄像头，作为批量导入默认值。选中已有录像，右侧选择所属摄像头→保存摄像头关联→查看影响数量并确认。不同/显式片段关联保留，旧冻结快照不改。标注工作台只显示来源摄像头并可跳转视频管理。
3. 抽帧列表显示时间与真实来源编号/文件名，完整来源见悬停提示。复选框有粗边框与对勾，Ctrl/Shift与全选继续可用。
4. 标注工作台的“标注状态”只有未标注/已标注；正常无框可完成，异常可按实际内容画框或标整帧。已剔除是独立无效状态，不代表训练标注。保存已标注不会自动审核。
5. 数据集管理→独立人工审核：逐张检查并勾选，选择DRAFT/REVIEWED/APPROVED/REJECTED→提交所选图片审核→明确确认。修改已审核内容后会提示需重新审核；旧审核记录保留，新版本不能直接放行。审核完成后再选择候选、冻结与导出。
6. 视频管理→查看下游依赖→从项目移除视频。有片段/帧/标注/数据集/训练/模型/任务引用时只能隐藏；勾选显示已停用/已移除录像可恢复普通列表。无依赖COPY默认保留项目副本，可在确认框明确清理；REFERENCE不删除外部原文件。已清理副本需从原录像重新导入，不能直接恢复空文件。旧数据及历史引用不删除。
