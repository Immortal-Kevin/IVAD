# IVAD v1.1 架构与当前边界

用户2026-10-26授权取代旧YOLO/P0路线。保留项目根名以稳定现有路径；不把其他NVIDIA项目进度带入本项目。

## 三个边界

- `src/Ids`：Apache-2.0权威数据模型、校验、文件与事务、完整/增量包。无AI依赖。
- `src/Annotator`：Apache-2.0自研C#/WPF桌面开发版。系统.NET Framework、Media Foundation为外部Windows组件；不随附运行时和字体。不使用Python/AI/联网服务。
- `src/Full`：私有业务代码，引用IDS；当前只有COCO矩形适配器和明确阻断的训练接口，不链接RF-DETR。NVIDIA训练环境未建立。

## 数据流

用户选择项目目录 → JSON实体与内容寻址媒体文件 → Media Foundation独立进程解码，读取样本时间 → WPF原图坐标画布 → 标注/审核/Revision → IDS完整包或增量包 → Full模型适配器。

视频抽帧保留独立进程；视频导入、流式hash/复制、保存校验、IDS导入导出通过Task.Run执行，UI只负责输入、完成后刷新和每200ms更新进度。Work上下文提供线程内取消与进度，VideoJobs负责子进程、取消文件、超时和本任务已创建资产记录。提交前校验在独占写锁内；取消在提交前生效，原子提交完成后不伪报撤销。没有持久多任务队列；非正常退出/断电恢复仍待验收。当前JSON/文件模型保持不变。

## 安全与隔离

路径穿越/保留文件名/大小写碰撞/链接/压缩大小等由导入器拒绝；先staging校验再提交。资产不可被包静默覆盖，增量基线冲突整体拒绝。项目存在并发变更时拒绝覆盖。尚需崩溃恢复和恶意大包压力验证。

非发行构建脚本只白名单编译Ids与Annotator，Full只进入私有开发测试。正式打包冻结。未来候选必须白名单收集代码和合规材料，禁止直接打包仓库、环境或数据目录。

## 当前技术选择与依据

Apache-only政策排除了默认采用MIT/BSD/LGPL的第三方GUI库。系统自带WPF和Media Foundation作为OS组件单独登记，不伪称Apache，不复制其二进制。不存在PySide/Qt/FFmpeg的新安装。真实测试覆盖当前Windows11开发机，不能外推Windows10/所有显卡/编码。

RF-DETR1.11.2核心代码、[train]候选依赖递归解析及小wheel许可证已审查；复合许可/二进制/权重和CUDA仍有阻断。治理脚本不自动安装，不执行审计下载的代码。
