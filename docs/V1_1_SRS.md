# IVAD v1.1 当前需求与验收范围

正式上位依据：prompts/IVAD_V1_1_AUTHORIZATION.md；许可Policy B.1。旧v1.0 SRS保留为历史，新授权有冲突时以本轮用户指令为准。

## 本轮MVP

| 能力 | 当前实现/验收范围 |
|---|---|
| 项目、厂区、设备、摄像头 | 本地创建/打开及稳定ID关联；中文GUI |
| 视频导入/抽帧/预览 | 复制原视频、hash、Windows解码、真实样本时间、帧选择预览 |
| 人工标注 | 原图像素矩形、多边形、ROI；保存/撤销保留修订 |
| 故障图库/审核 | 故障类型记录与版本字段、按故障预览已有标注帧、四种帧状态、审核与修改记录 |
| IDS1.0 | 全部要求实体、引用/坐标校验、资产hash、完整/增量双向交换、基线冲突拒绝、失败回滚、不可覆盖快照 |
| Full边界 | 独立RF-DETR审查、IDS到COCO矩形映射、阻断式训练接口；无训练成功声明 |
| 治理 | A–L Gate、来源/hash/license/NOTICE、分产品状态、正式发行冻结 |

## 明确的部分实现/未实现

基础GUI可启动，核心服务测试通过；实际鼠标交互端到端尚未完成人工验收。图库为已有故障帧浏览，类别重命名/弃用迁移、顶点增删、缩放平移、完整撤销重做、复杂多边形拓扑、视频播放器时间轴、持久多任务队列仍待扩展。已有顶点拖动、矩形移动/四角调整/软删除和单任务进度/取消本轮已实现；真实GUI完整交互仍NOT TESTED。

完整与增量交换可运行，分叉冲突检测采用拒绝整个合并；逐字段冲突UI未实现。快照已不可覆盖，但训练/验证/测试跨录像分组拆分未实现。断电恢复、海量数据、跨版本迁移仍需验收。

无AI自动标注、无正式RF-DETR训练、无生产检测报警、无公开仓库、无正式安装包。Windows10/AMD/NVIDIA多机、实际禁网、升级卸载、CUDA再分发均未验收。

## 验收原则

真实测试、静态、模拟和未测试分开；未知许可阻断。源码存在不代表功能已通过；开发EXE编译不代表Windows发行可行性完成。用户数据本地私有，不随开源代码发布。正式打包、签名、分发必须另获批准。
