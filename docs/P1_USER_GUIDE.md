# IVAD P1 使用说明

当前版本：1.0.0-P1。当前可用的是项目与应用基础；视频、标注、工业训练、检测和报警尚未实现。

## 启动和退出

在本项目目录双击 **启动IVAD.cmd** 即可打开软件，不需要输入Python命令。
首次打开会在后台检查GPU；检查期间可切换页面或管理项目。正常关闭窗口会取消未完成的非AI诊断任务、等待设备检查结束并关闭数据库。设备检查极端情况下有超时上限，关闭可能需要等待。
同一应用数据目录同时只允许一个主程序实例；再次启动会提示已有实例。
如果提示缺少P1环境，交给Codex恢复独立环境，请不要改全局Python、CUDA或ComfyUI。

## 新建和打开项目

1. 在“开发模式”点击“项目管理”。
2. 输入项目名称，按需填写厂区信息和描述。
3. 点击“新建项目…”，在目录选择器中选择**存储父目录**。
4. 软件自动创建一个`IVAD-UUID`子目录并打开；UUID是稳定身份，修改显示名称不会改变它。
5. 修改项目信息后点击“保存配置”。
6. 点击“一致性检查”，检查目录清单、数据库UUID、Schema版本及数据库完整性。

“打开项目…”选择含`project.json`的项目目录；也可双击最近项目记录。路径失效时会提示错误，现有项目不会被删除。关闭项目不会删除任何文件；有未保存修改时可取消关闭，先保存后再关闭。
项目管理页的输入字段也可用于创建另一个新项目；打开、关闭和退出现有项目时会检查未保存修改。失败的保存会保留输入字段，以便修正后重试。
不要手动修改`project.json`或SQLite。迁移整个项目时，在应用关闭该项目后复制完整项目目录，再在软件中选择新位置；内部数据库引用为相对路径。P1没有媒体导入和项目删除功能。

## 双工作空间

右上角可切换“开发模式”“生产监控模式”。两者使用同一软件和服务。
后续页面会明确显示`Not Implemented · 尚未实现`和计划阶段，不会产生虚假检测、报警或示例生产数据。生产模式的“系统状态”可查看本机设备。
左下方“任务中心”“设备与后端”“诊断日志”在两个工作空间均可使用。导航列表在窗口高度较小时可滚动；右侧上下文面板可通过分隔条调整宽度。

## 任务中心

“提交非AI诊断任务”运行约3秒的可取消基础设施测试；它不是视频检测或AI训练。
“测试异常处理”会有意产生一个可控失败，便于确认失败日志及队列后续任务仍可运行。此功能明确标记为测试，不是实际业务失败。
选中任务可“取消选中任务”或“查看任务日志”；已完成任务不能取消。状态可能为QUEUED、RUNNING、SUCCEEDED、FAILED、CANCELLED、INTERRUPTED。
正常关闭时未完成任务会取消；意外退出后丢失Worker的任务会在重启时标为INTERRUPTED。P1不支持继续执行原Worker，请重新提交诊断任务。
界面显示最近200个任务；其余历史仍保留在数据库，P1尚无分页界面。

## 设备与系统设置

设备页真实显示GPU名称、驱动、显存和后端状态。“硬件检测”与“后端可用”“实测验证”分别显示。
NVIDIA的验证状态必须匹配P0实际测试证据及当前软硬件。P1检查只运行小型CUDA张量探针，不重新训练/推理YOLO。当前Intel集显显示Not Tested；原B390历史P0 BLOCKED仍独立保留。
系统设置可选择可信GPU环境的`python.exe`，并选择首选GPU；默认使用本项目P0 NVIDIA环境。仅保存设置，不安装或修改该环境。手动选择的设备失效后不会悄悄改用其他设备或CPU。
Worker路径失效时，设备页显示后端Error并保留能枚举到的物理GPU信息。P1未提供AI执行按钮；以后AI任务也必须通过GPU检查。
当前仅简体中文，英文语言包未实现；Qt翻译入口已保留。

## 日志与问题处理

“诊断日志”查看摘要，选中条目查看技术详情；“复制诊断信息”复制已脱敏的摘要及日志，便于交给Codex排查。界面时间为北京时间，原始日志时间为UTC。
应用设置、最近项目、任务、设备检查缓存及日志索引位于项目目录`runtime`；日志文件在`runtime/logs`。不要清空此目录来“修复”问题。
数据库错误或未知Schema会停止打开，不会自动覆盖原数据；迁移前会在原数据库旁保存迁移备份。P1尚未提供完整备份恢复GUI，遇到损坏请停止继续操作并保留文件，由Codex诊断。

## 当前限制

没有正式Windows安装包、自动部署、用户登录、网络服务、RTSP、视频管理、标注、工业训练、生产模型发布、检测或报警。以上按后续阶段逐一验收，未经批准不会开始。
仅本机Windows11/RTX5070 Ti环境实测，其他机器需要独立验证。项目和程序可以复制，但venv依赖原基础Python路径，并不是可移植安装包。
