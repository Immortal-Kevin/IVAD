# P3.7-A RF-DETR Nano训练操作说明

本功能为工程实验；LIMITED数据不代表独立工业验证。保持打包冻结，尚未接入离线视频RF识别（P3.7-B未授权）。旧YOLO记录保留，但RF任务不会调用旧引擎。

1. 用现有源码启动方式打开IVAD，进入开发模式并打开正确项目。初次验证建议使用项目副本。
2. 在“AI训练”选择已冻结的数据集版本，再选择 `rfdetr-nano`。不重新划分冻结集。`8525test1 v1`保留200图、402框、16正常负样本和160/40/0划分；LIMITED继续有效。
3. 简易训练默认1轮、384分辨率、批量4、梯度累积1、AdamW学习率0.0001、骨干学习率0.00015、BF16、EMA。它用于短验证，不是工业效果保证。高级训练可调整专属参数，悬停查看中文说明；不会套用YOLO的SGD/imgsz/lr0。
4. NVIDIA GPU必须显示RF CUDA可用。没有GPU不能训练，不会转CPU。BF16不支持时需明确选择FP32；不要把无CUDA当作显存不足。
5. 初始权重可选已核实本地官方Nano COCO权重，或同类别UUID的已登记RF模型。禁止YOLO/PT/ONNX/恢复CKPT冒充RF初始化。官方PTH缺失或哈希错误会停止，不自动下载或回退。
6. 点击“训练前检查”，通过后点击“启动GPU训练”。修改配置后必须重新检查。任务参数提交后固定；可以在任务中心查看排队和错误。
7. 选中训练记录查看状态、参数、指标及真实Worker日志尾部。RF不一定生成旧YOLO的results.png；以实际指标与日志为准。最终登记指标统一使用FP32官方验证协议，不能与原生训练BF16日志直接比较。
8. 需要停止时点“取消所选训练”，或从任务中心取消排队任务。系统先在batch边界取消，超时只停止本次Worker进程树；历史记录和已有检查点保留。失败或取消不登记成功模型。
9. 成功后进入“模型仓库”并点击“刷新”，查看独立RF UUID、EXPERIMENTAL状态、SHA256和真实指标。完整性检查仅查文件哈希；GPU重载验证需返回“AI训练”，在初始权重选择该模型，再点击“验证所选初始模型”。
10. 正常关闭并重新打开项目后，训练及模型记录仍应存在。新模型不会替换摄像头正式模型，也不会修改冻结数据或旧YOLO权重。

`.pth`是RF模型权重，`.ckpt`是Lightning训练状态/优化器检查点；不能只改扩展名。上游PTH可以附带优化器/Lightning元数据，系统检查真实的model权重布局，不因看到优化器字段就误拒绝，也不接受只有state_dict的恢复CKPT改后缀冒充。取消CKPT保留，但本轮没有开放优化器断点恢复。模型仓库通用“导入可信模型”目前仍用于历史PT/ONNX；RF经正式训练/验证服务自动登记，不走这个未验收的手工PTH导入入口。原P3.6实验权重保持原位置，本轮不将其冒称GUI新训练模型。

“导出模型权重/ONNX”对RF只导出已登记PTH及元数据，不自动产生ONNX。P3.6已有ONNX实验结果保留，正式离线视频迁移、ONNX运行接入及旧缓存隔离属后续P3.7-B。
