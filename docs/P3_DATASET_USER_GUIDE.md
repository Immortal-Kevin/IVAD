# P3 数据集管理操作指南（源码版）

适用：2026-10-15数据集Hotfix；打包冻结，不更新Word/PDF手册。

## 1. 图片列表与筛查

**目的：** 从P2已保存的人工标注中筛选实验检测样本。

**步骤：** 打开项目→数据集管理。顶部“所属摄像头”初次优先沿用当前标注摄像头，缺省选择有合格图片的单个摄像头；可明确切换“全部摄像头”或“未关联摄像头”。继续选择故障类型、处理结果、来源、标注完成和剔除状态。默认“仅有效图片”隐藏已剔除帧。点击列标题按摄像头、抽帧时间或故障类型排序；表格可水平/垂直滚动。鼠标悬停单元格查看UUID、SHA256、来源路径及自动检查问题。

**正常结果：** 主列表显示摄像头、当前媒体内部相对秒数（由原始PTS减媒体起始时间派生，原始PTS保留在详情）、录像名、处理结果、故障类型及目标数量；多类别按类别汇总。“整帧异常 / 无目标框”明确显示但不能加入Detection。

**常见问题：** 筛选变化会清空勾选，防止隐藏图片进入操作；已经添加的数据集草稿成员保留，在“新建数据集”页可检查。可见且未剔除不代表已经符合训练准入。

## 2. 批量选择、排除和恢复

**目的：** 管理候选和无效帧，不删除原文件。

**步骤：** 在表格上方勾选或点击“全选当前结果”“全选正常”“全选异常”；这些批量选择仅选择当前可见且合格的检测候选，不选剔除、冲突或无检测目标的整帧异常。可用“取消选择”清空临时勾选。右侧统计候选、已选、正常已选、异常已选，悬停查看操作说明和当前来源。“从候选列表排除”仅影响当前数据集会话草稿，同时移除其草稿成员；“恢复候选排除”重新显示这些图片，不自动重新加入草稿。“标记所选为无效帧”需要确认，将全局软剔除；在“仅已剔除图片”中勾选后点“恢复已剔除图片”。

**正常结果：** 显示成功、跳过、失败数量；原图片、人工标注历史和旧冻结版本保留。

**常见问题：** 候选排除和草稿是当前窗口会话状态，重启不保留。全局剔除保存在项目中，影响之后新版本及训练前校验；不会改写旧版本文件。本轮没有永久物理删除。

## 3. 新建数据集

**目的：** 将有效的人工真值加入独立实验草稿。

**步骤：** 在图片列表勾选→切换“新建数据集”→输入名称或选择已有数据集→查看“当前待添加X张”及筛选/勾选/正常/异常/无效/草稿计数→“添加所选图片”→“检查候选数据”。多摄像头共享集需明确勾选“允许多个摄像头/未关联来源”。

**正常结果：** 只添加合格样本；未知、冲突、剔除、缺失、非法目标或整帧异常无框被跳过。草稿中逐行列出摄像头、录像、PTS和故障类型。不同数据集草稿按选择的Dataset UUID隔离；创建新数据集在冻结时正式写入数据库。

**常见问题：** 本轮取消重复逐张审核UI，但不改写DRAFT/REVIEWED/APPROVED/REJECTED。自动检查通过的人工真值可进入实验版本，并记录AUTO_CHECKED_HUMAN；不冒充独立审核，历史审核拒绝仍阻止准入。正常负样本必须人工确认正常且无异常对象/类别。

## 4. 训练集划分设置

**目的：** 准备可追溯的Train/Val/Test并识别泄漏风险。

**步骤：** 选择“按来源视频分组（推荐）”“按摄像头分组”或“随机图片划分”。设置Train（训练集）、Val（验证集）、Test（测试集），合计100%；默认70/20/10。随机种子默认123，控制相同条件下划分重复性。各输入框可悬停查看用途。点击“预览划分与数据泄漏检查”。

**正常结果：** 显示预计图片数、实际图片数、来源组/划分组数量、类别映射、问题和PASS/LIMITED/BLOCKED。来源视频分组递归追溯片段原视频，同源不跨集合；摄像头分组保持整机位同组。精确SHA256重复去重并报告，跨集合近似哈希距离≤4提示高相似风险，不自动删帧。

**常见问题：** 同一个录像的200帧仍只有一个独立来源。按来源分组时可能只有Train，缺Val/Test为LIMITED，不能训练（训练前仍要求Train和Val非空）。需要增加真实独立录像或摄像头。随机图片划分必须明确勾选泄漏风险，并且始终为LIMITED；仅在勾选“工程管线测试”后允许冻结隔离实验版本，不代表工业准确率。实际分组按组分配，图片数量不保证精确达到百分比。日期/工况/时段策略暂不支持，后续可扩展策略接口。

## 5. 数据集版本与导出

**目的：** 冻结不可变快照并为YOLO准备标签。

**步骤：** 检查草稿与划分→切换“数据集版本”→“冻结新版本”→确认→在任务中心等待成功→选择历史版本查看类别/划分/验证等级→“检查选中版本完整性 / 来源”查看逐样本来源与文件校验→选择“YOLO Detection”→“导出选中冻结版本…”→选择已有父目录。

**正常结果：** 每次新建版本目录，复制并校验图片、保存真实标注与来源快照、类别映射、审核原值、实验政策及风险确认，不覆盖旧版本。正常帧生成空检测标签，多边形按外接框导出Detection且原多边形保留在原生旁车；整帧异常不能伪造检测目标。导出任务显示结果路径和校验结果。

**常见问题：** 冻结前再次校验文件、真值、摄像头关联、类别及来源；过程中修改会阻止提交。冻结历史可追溯，但之后全局剔除的图片仍会让相关版本的训练前检查拒绝，应新建合适版本。实验准入仅供P3实验，模型生产注册仍保留人工批准要求；不得将其当成生产验证。


## 2026-10-15 v2时间与选择说明

顶部筛选已改为两行行内标签；四个Tab保留。底部根据未打开项目、当前无图片、当前显示/已勾选数量动态提示；读取失败显示错误。Tab切换保留勾选，同范围后台刷新保留仍可见的勾选，主动改变筛选清空勾选；已经添加的草稿独立保留。添加后区分成功、重复跳过和不合格失败，重复添加不会重复计数。

勾选是临时选择，“添加所选图片”是当前会话草稿成员，“冻结新版本”才写不可变快照。多个摄像头加入同一草稿仍须明确共享授权。管理已剔除图片时可逐项勾选再恢复；训练“全选”不会选择已剔除图片。

“抽帧时间（秒）”显示当前媒体相对位置；片段的原视频相对位置可在tooltip查看。媒体内部相对秒不等于摄像头画面拍摄日期。8525例：原PTS 52247677778µs、起始PTS 52241877778µs，对应5.800秒，不能把原PTS直接除一百万显示为52247.677778秒。原始PTS与历史time_us不改写；片段映射使用实际first_source_time_us，不猜申请起点。历史缺少可信映射的片段显示来源时间未知，需后续核查。
