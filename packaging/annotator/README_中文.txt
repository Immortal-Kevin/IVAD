IVAD Annotator v1.1 测试版 — 1.1-test.20261026.01
Windows x64 Portable（依赖系统 .NET Framework，不是 self-contained）

一、启动
把整个 ZIP 解压到本地可读目录，不要在 ZIP 内直接运行。
双击 IVAD.Annotator.exe。EXE.config 必须与 EXE 放在一起。
软件运行不需要开发工具、Python、CUDA、独立显卡或管理员权限。
需要 Windows 10/11 x64、.NET Framework 4.8 或更高4.x，以及系统媒体组件。
.NET 8/9/10 Desktop Runtime 不能代替 .NET Framework。
可双击“检查运行环境.cmd”作只读检查；不会下载、安装或更改系统。
缺少环境时按 RUNTIME_REQUIREMENTS.txt 的 Microsoft 官方说明处理。
这是未签名的内部测试包；如果 Windows 或企业策略阻止运行，请交管理员审核，勿关闭防护或绕过策略。

二、项目和连续标注
项目 → 打开项目主目录 → 选择一个可写主目录 → 填写厂区/设备/摄像头 → 保存并打开摄像头项目。
已有项目可检测现有文件夹，原地打开。数据保存在所选主目录/厂区/设备/摄像头。
视频与抽帧 → 导入视频 → 选择时间范围、间隔、最多新增帧 → 执行抽帧。
标注与审核 → 选择/新增故障类型 → 绘制矩形，完成几何编辑会自动保存。
右下 Ctrl+S / 保存并下一帧：有异常标注则保存异常，没有异常标注则保存正常，保存后换帧。
标记正常：保存正常并换帧，不删除已有几何。ROI不算异常。
未完成绘制会保留草稿并提示先完成或取消；末帧停留并提示。
工具和故障类型保留。未知等指定状态在“记录与图库 → 保存所选帧状态”处理。
IDS → 导出 IDS 包。可未标完就导出，未标注帧仍保留。
导入 IDS 包时选空目录；先校验哈希与关联关系，冲突拒绝覆盖。
关闭后从主目录检测重新打开，数据保留；不会自动记住上次帧位置。

三、保存与日志
业务数据留在用户选择的目录，不放入程序 ZIP，不会随软件删除。
优先将数据放在普通用户有写权限的本地磁盘，预留源视频复制、图片及IDS导出空间。
应用日志在程序目录 logs；若无写权限则尝试 %LOCALAPPDATA%\IVAD Annotator\Logs。
程序目录可只读；业务目录必须可写。不要同时使用多个版本编辑同一项目。
异常退出后重新打开可找回最后已提交的数据；未完成绘制不保证恢复。
project.ids.json.backup 是上次清单备份。发生损坏时保留整个项目再排查，勿覆盖现有数据。
不自动清理未知临时文件或旧资产，不宣称断电零丢失。

四、另一台电脑复验
1. 校验 ZIP 的 SHA256（随交付报告提供），解压后可按 checksums.sha256 核对文件。
2. 检查系统/.NET/媒体组件，普通权限启动；创建中文、含空格的测试主目录。
3. 用自己许可的非敏感 MP4/H.264 或 AVI，导入并抽帧。
4. 有框/无框各按一次 Ctrl+S，返回检查异常/正常、几何、下一帧及工具保留。
5. 关闭重开，导出 IDS，在另一个空目录导入，核对帧数、标注和审核。
6. 检查100%/125%/150%/200%缩放、1920×1080及2K屏幕布局；记录系统、显卡和结果。
不要把业务视频或私人日志发到公网。无需安装训练组件。

五、验收边界
本包仅获本次指定测试电脑的拷贝测试交付授权，没有公开发布授权。
A：最终内容许可证与材料由本机打包审计核对。
B：本机独立目录可执行验收见包外交付报告；内部命令调用不等于真实鼠标/键盘验收。
C：其他Windows电脑实际运行一律 NOT TESTED，待收到实测记录才改变。
内置 --deployment-check <全新空目录> 可选诊断会创建合成AVI和测试项目、运行实际媒体/IDS及内部WPF命令；不是真实GUI自动化。
--deployment-reopen <同一诊断目录> 可在新进程核对已保存数据。正常使用无需这些参数。
