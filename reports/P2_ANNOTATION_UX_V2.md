# P2 标注工作台第二轮交互优化

日期：2026-10-14。工程1.0.0-P2-UX.2，便携候选1.0.0-P2-Beta.2，Schema0005。仅P2，未进入P3–P6。

## 实现与界面

在既有AnnotationPage增量添加处理状态、快捷区、摄像头和批量按钮，无第二套页面。左侧图片列表为复选框+图标+真实时间+短UUID；底部三行双列紧凑按钮，不挤占全部列表。右侧属性滚动，普通保存保留。Ctrl+S普通保存，Ctrl+Enter快捷保存；每个功能也可鼠标操作。

处理状态从既有Annotation推导：无文档UNPROCESSED、NORMAL正常、ABNORMAL异常、UNKNOWN文档UNCERTAIN；正常含目标/类别为CONFLICT。Frame.handling.is_excluded覆盖为EXCLUDED。审核DRAFT/REVIEWED/APPROVED/REJECTED独立，不以有无框判正常，不复制另一套分类字段。旧文档及所有修订保留。

选正常清空整帧故障类别并禁用该下拉和目标绘制工具；ROI可选。已有目标/整帧故障/已审核异常时先确认，取消保持原内容；明确确认后先保存未提交旧内容，再清除目标、转DRAFT并保存新修订。可“恢复历史标注…”产生新的恢复修订，旧修订及ROI不删除。撤销恢复目标时同步返回异常状态，避免正常与框冲突。服务层也拒绝未经确认的异常→正常覆盖。

快捷按钮随正常/异常/未知显示，成功保存才下一张；复选框关闭自动跳转后仅保存。默认开启，应用设置持久化。不自动APPROVED。异常无框可保存，YOLO不可当正常负样本，原生标签语义保留。未知可填原因，不能等同无效帧。

下拉/弹出项保持白底深字；新增QDialog/QMessageBox浅底，修复系统深色背景导致摄像头对话框文字低对比。20余个控件沿用同一stylesheet。

## 附带发现与修复

页面刷新中再请求刷新原先被直接丢弃：并发保存新类别可能暂不出现。现在合并pending刷新，并有真实阻塞旧收集结果的定向测试。摄像头未保存选择原先可能被异步刷新重置：现在按同录像保留选择、用generation忽略旧回调，关联前等待图片加载/标注保存。数据库已达目标版本时不重复执行Alembic升级，仍做只读完整性/版本校验，真正升级仍先备份。
