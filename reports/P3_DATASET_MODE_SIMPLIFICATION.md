# P3 数据集验证模式简化

2026-10-16。验证范围与资产保护见P3_WORKFLOW_GUI_HOTFIX.md。

工程实验（默认）：允许LIMITED工程用途，保留真实风险状态，不提升为PASS/生产批准。小样本来源不足可随机图片划分以测试管线，记录跨源泄漏及无Test风险；标准模式仍优先完整来源组，不为比例拆组。

严格验证：不启用工程随机回退，任何LIMITED（来源不足、缺少有效集合/类别或泄漏）转为BLOCKED，不能冻结宣称严格合格的版本。严格结构通过也不代表工业生产验收。

两种模式均拒绝缺失/损坏图片、无效类别/几何、引用损坏、冲突、剔除或不符合Detection的标注。原审核字段保持；实验政策human-auto-v1不替代独立人工审核。

工程LIMITED首次检查返回待确认状态，用户明确确认后服务重新计算签名并CAS保存risk_ack；绑定样本、类别、来源、风险、划分结果及完整配置。同结果重复检查不再确认；成员/标注/来源/参数改变后重新检查，保存新修订会清除旧确认。拒绝确认不允许冻结。风险签名及模式进入新快照准入元数据，历史版本原状保留。

采用“点击检查先原子保存全部待处理成员和配置”，不是每次切预设自动写库。保存时禁用编辑防竞争；未保存成员随本次保存明确一并处理，不丢弃。UUID不变、修订冲突拒绝、失败不检查。无数据库字段删除或migration。

测试覆盖确认前禁止冻结、确认后冻结/重复检查、配置改变重确认、严格阻断、两模式图片损坏阻断、保存失败、同UUID及200成员重开/旧v1不变、新v2。独立真实副本为单来源160/40/0 LIMITED；不是独立工业验证。工程/严格并未修改原项目历史数据。
