## 本轮实现

| 区域 | 修改与边界 |
|---|---|
| 窗口 | 显式标准 Windows 标题栏、可缩放/最小化/最大化/关闭；按工作区确定默认大小；右上增加退出。三栏随窗口宽度调整，分隔条可拖，预览等比缩放，左页可滚动，工具栏换行，默认字体14。 |
| 视频 | “导入视频”位于原视频选择上方，与抽帧分离；抽帧按钮位于视频页最后。图片列表上方显示进度条、当前/总数和阶段。后台先按真实PTS、范围、间隔及去重规则统计总数，再抽取与保存。 |
| 标注 | 图片上方只读显示当前项目、设备、源视频摄像头；工具栏提供选择/拖动、矩形、多边形、ROI、删除、完成多边形、正常、保存并下一张。保留角点调整和软删除历史。 |
| 审核 | 非“本地管理员”隐藏审核结果；正常或完成故障标注后保存默认确认。未知且无标注保留未知，未完成且未标注不能误确认。提交成功才换下一帧，保留故障输入、故障类型ID和工具；最后一帧停留并提示。 |
| 主目录 | 选择主目录、检测文件夹、填入/选择厂区设备摄像头、保存打开；新项目按三级目录建立，已有空目录沿用。检测旧项目元数据，原地打开、不迁移、不覆盖、不重建ID。检测限三层/一万个目录，不跟随链接。 |
| IDS | 主界面仅导出/导入/另存为IDS；内部完整/增量代码保留。默认名为厂区-设备-摄像头-日期.ids，冲突附-01、-02，不覆盖。旧包扩展名兼容。 |
| 保存/退出 | 完成的几何编辑自动保存；未保存审核或未完成绘制在离开时提示。忙碌关闭请求取消并等待清理。保留正在运行的旧EXE，不强制结束用户窗口。 |

新增 `Workflow.cs` 只封装本轮UI目录/命名/审核/换帧策略，IDS结构不变，没有新第三方依赖。Windows .NET/WPF/Media Foundation仍作为外部系统组件，不随产品复制。

## 问题与修复记录

1. 固定侧栏和不明确退出入口：标准窗口配置、工作区默认大小、动态栏宽/分隔条、滚动/换行；系统按钮仍待真实验收。
2. 导入即抽帧、上限冒充总数：拆分流程，增加不修改业务数据的真实PTS统计。代价是额外一次解码；每遍五分钟，父进程610秒总上限。取消可终止无响应子进程；抽取结束与保存成功分开显示。
3. 审核后停留/选择丢失：成功提交后顺序换帧，验证故障、工具、末帧行为。
4. 新列表模板绑定字段可能为空：Choice改为属性，显式换行绑定。
5. 草稿/审核选择静默丢弃：离开提示；取消切帧恢复选择时避免清除草稿；几何提交保留未保存审核选择。
6. 目录与命名覆盖风险：非法路径、链接、关联不一致拒绝；包重名加序号，底层导出仍不可覆盖。
7. 首次编译CS0016（运行中EXE占用）：先编译临时工件，原EXE保存在项目内`build/dev-history/`，再替换开发路径，失败可回退。未结束旧进程、未移动业务数据。
8. 新增内部WPF测试首次缺少Dispatcher同步上下文，后台continuation跨线程访问控件，测试进程退出。已为内部测试建立同步上下文，修复后21项通过。两次失败Gate和Windows .NET Runtime原始事件保留；不能推定为已确认的真实鼠标运行故障。
9. 初始合成渲染背景透明，黑色文字在黑底预览不可读：显式使用系统控件背景后重新检查。客户端PNG仍不能证明系统标题栏表现。
10. computer-use读取用户已打开窗口被自动审批拒绝，原文`Computer Use was not approved to use dev`。未给更具体原因，不解释为WPF缺陷。没有绕过审批，也没有在业务项目上做测试。
