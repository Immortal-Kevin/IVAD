# Annotator 双阶段 UI/UX 改版

日期：2026-10-26。本轮仅修改WPF界面、样式与界面导航，不改变IDS数据格式、许可证政策或分发冻结。

## 页面结构与控件迁移

| 入口 | 现在放置的内容 |
|---|---|
| 左侧「项目」 | 主目录选择/检测、项目名称、厂区、设备、摄像头、保存打开。作为独立设置页，不再占据视频/标注工作区。 |
| 主Tab「视频与抽帧」 | 左侧导入、源视频、起止时间、间隔、最多新增帧、执行抽帧；中间任务进度/数量/状态与当前源视频帧列表；右侧原视频播放/暂停、抽帧图片预览。 |
| 主Tab「标注与审核」 | 左侧故障类型、工具、状态、审核人/管理员结果；中间帧列表与已确认数量；右侧图片、项目设备摄像头、本帧标注折叠区、上一帧/下一帧。蓝色「保存并下一帧」固定在左侧底部。 |
| 左侧「IDS」 | 导出、导入、另存为；未标完也可导出当前已提交数据。主界面无基线/增量术语。 |

主Tab严格只有两个。新增故障类型、记录与图库、本帧标注明细默认折叠。绘制工具集中于左侧，取消重复的整排工具选择按钮；完成形状、取消绘制、删除仍可直接操作。原有故障/工具选择保留、审核后换帧、自动保存、关闭提示和后台取消继续使用。

上一帧/下一帧有边界保护；切换阶段保留当前帧与故障/工具状态，存在未完成编辑时沿用提示机制。项目与IDS页面不删除或重置工作区内的标注草稿。帧状态在列表中以中文显示。

## 手动查看

1. 保存并正常关闭旧窗口；正在运行的旧版不会自动刷新界面。
2. 启动 `build/dev/Ivad.Annotator.Dev.exe`，完整路径见 `docs/ANNOTATOR_QUICKSTART.md`。
3. 左侧「项目」打开原目录，依次查看两个主Tab；确认视频页没有审核字段、标注页没有抽帧参数。
4. 在视频页查看进度和原视频播放；在标注页绘制、查看本帧标注、上一帧/下一帧、保存审核并继续。
5. 最大化及调整窗口检查布局，下拉框输入和选择、折叠区和滚动区需人工复验。

本轮没有生成正式安装包、签名、公开发布或解除冻结。
