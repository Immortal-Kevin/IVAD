## 根因与实现

旧TrainingPage.mode回调直接禁用整个advanced分组，属于简易模式行为，并非RTX硬件锁定。现简易模式按DEFAULTS显示推荐值、单个输入只读；高级模式可编辑。参数与标签/控件有中文Tooltip，WA_AlwaysShowToolTips支持禁用时阅读；基础权重/恢复及5操作按钮也有说明。

宽窗口基础/参数40:60顶部对齐，窄窗口上下排列。五动作顺序刷新、预检、启动、验证初始模型、取消；宽窗口同行，窄窗口换行，无重复按钮。真实Qt截图及尺寸见P3_WORKFLOW_GUI_HOTFIX.md。

| 参数 | GUI/服务/Worker |
|---|---|
| epochs | 1–10000整数 |
| imgsz | 64–2048且32倍数，非法即时提示 |
| batch | 1–64 |
| patience | 0–10000，0关闭早停 |
| seed | 0–2147483647 |
| lr0 | 0.000001–1 |
| weight_decay | 0–1 |
| optimizer | SGD/Adam/AdamW/auto，真实透传Ultralytics |
| augment | bool，关闭映射Worker已有增强禁用参数 |
| amp | bool，简单默认False；高级有可用NVIDIA后端才开放 |

Worker源代码真实应用参数；AMP运行时先本地CUDA自动混合精度探测，再执行训练。未改Worker环境或启动真实AMP训练。参数传递测试使用明确标记的假Child读取request.json并失败退出，验证全部10项无丢失，失败无模型注册；此为接口测试，不是GPU训练成功证据。

## 行为验证

- 未通过当前配置预检不允许启动，关键参数/版本/模型/GPU/权重/恢复选择变化使预检失效。
- configuration_preflight复用冻结图片/类别/几何/来源校验，校验参数、NVIDIA后端、Worker解释器存在、权重哈希/架构、恢复数据版本/架构/检查点；启动前再次执行，结果变化拒绝排队。
- 后台预检不阻塞GUI；启动提交期间防重复，测试连续调用只提交1次。后续有意重新预检才能新建下一任务。
- 精确TrainingRun取消确认，拒绝不取消、确认只取消指定job；已完成历史不删除。
- 恢复训练时参数显示原任务实际值并只读，Tooltip解释沿用原值，不能修改无效配置；初始权重选择同时禁用。
- 记录JSON展示actual_parameters；新任务表单不写入正在运行的记录。
- 已完成模型通过初始权重作独立微调；恢复只提供失败/取消任务并沿用原参数及优化器进度。保持既有独立续训记录/目录，原记录不覆盖，非原记录原地更新。
- 验证初始模型仍是独立GPU验证任务，非新训练最终效果；任务中心、GPU资源队列与ModelRegistry逻辑未重构。

CPU拒绝、结构错误阻断、YOLO导出/正常负样本/多类别、快照不可变、模型哈希及状态门槛、Worker OOM/崩溃日志与队列继续执行均在针对性回归覆盖。真实历史训练/指标保持不变。
